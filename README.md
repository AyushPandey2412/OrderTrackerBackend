# Order Tracker API

A simple Node.js + Express + PostgreSQL backend for managing customer orders.  
Includes full CRUD operations and a dashboard summary endpoint.

---

## Features
- Get all orders
- Get order by ID
- Create a new order
- Update an order (PUT)
- Partially update an order (PATCH)
- Delete an order
- Get dashboard analytics (total orders, revenue, status breakdown)

---

## Tech Stack
- Node.js
- Express
- PostgreSQL
- pg (node-postgres)
